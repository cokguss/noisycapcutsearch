## BAGIAN II: KETENTUAN LAYANAN & PENGGUNAAN (TERMS OF SERVICE)

### Pasal 4: Kepatuhan Terhadap Platform Pihak Ketiga
1. Noisy CapCut Template Search beroperasi dengan berinteraksi pada layanan dan Application Programming Interface (API) pihak ketiga (CapCut beserta CDN-nya, penyedia pool proxy publik, dan infrastruktur hosting yang Anda gunakan).
2. Pengguna memahami sepenuhnya bahwa setiap platform memiliki Ketentuan Layanan masing-masing, termasuk aturan hak cipta atas template dan konten yang beredar di platform tersebut.
3. Segala akibat dari penggunaan Noisy CapCut Template Search — termasuk namun tidak terbatas pada pembatasan akses oleh platform, klaim hak cipta atas template, atau pelanggaran ketentuan platform — adalah **tanggung jawab penuh Pengguna**. cokguss tidak bertanggung jawab atas kerugian tersebut.
4. Pengguna wajib menghormati hak kreator. Setiap template, cover, video, dan statistik berasal dari listing publik capcut.com dan tetap milik kreatornya; penggunaan template tetap tunduk pada alur dan ketentuan CapCut.

### Pasal 5: Ketersediaan Layanan & API Pihak Ketiga
1. Noisy CapCut Template Search disediakan secara **gratis** tanpa skema berlangganan apa pun.
2. Noisy CapCut Template Search bergantung pada listing publik CapCut dan pool proxy pihak ketiga yang dapat berubah, membatasi, atau berhenti sewaktu-waktu di luar kendali cokguss. Kegagalan fungsi pencarian akibat perubahan pihak ketiga bukan merupakan cacat produk maupun kewajiban ganti rugi.
3. Hasil pencarian identik di-cache selama lima menit, dan hasil kosong hanya di-cache singkat; perilaku cache dapat berubah mengikuti pembaruan perangkat lunak.
4. Sebagian template tidak menyertakan pratinjau media pada listing publik; template semacam itu difilter dan tidak ditampilkan, dan pratinjau penuh selalu tersedia melalui halaman resmi CapCut.

### Pasal 6: Privasi Data
1. Noisy CapCut Template Search tidak meminta registrasi akun dan tidak mengumpulkan data pribadi Pengguna.
2. Kata kunci pencarian dikirim ke server sesaat untuk dijawab dan tidak digunakan untuk membangun riwayat atau profil Pengguna; preferensi tema dan bahasa tersimpan lokal di peramban Pengguna (localStorage) dan tidak pernah dikirim ke mana pun.
3. Server tidak menyimpan berkas milik Pengguna, tidak memasang iklan, pelacak, atau analitik pihak ketiga, dan hanya mencatat log server standar oleh penyedia hosting untuk pencegahan penyalahgunaan.
